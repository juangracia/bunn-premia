# BUNN Premia 3D product study

An interactive 3D study of the BUNN Premia commercial coffee brewer, viewable in the browser.

**Live viewer:** https://juangracia.github.io/bunn-premia/

Drag to orbit, scroll to zoom, right-drag to pan. Preset camera views, a turntable toggle, and a studio brightness control are in the sidebar.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The viewer page, with the `model-viewer` library bundled inline |
| `BUNN_Premia.glb` | The model, glTF binary, 10.4 MB |
| `SOURCES_AND_NOTES.md` | Reference and modeling notes |
